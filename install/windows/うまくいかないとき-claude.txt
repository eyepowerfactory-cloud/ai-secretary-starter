━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. スタートボタンを右クリック →「ターミナル」（または「Windows PowerShell」）
  2. 下の1行をコピーして貼り付け → Enter（Git が入ります。青い画面は「はい」）

     winget install -e --id Git.Git --source winget --accept-package-agreements --accept-source-agreements

  3. 終わったら次の1行を貼り付け → Enter（Claude Code が入ります）

     winget install -e --id Anthropic.ClaudeCode --source winget --accept-package-agreements --accept-source-agreements

  4. ターミナルを一度閉じる（右上の ×）
  5. デスクトップに「AI」という名前のフォルダを作る（右クリック →新規作成 →フォルダー）
  6. AI フォルダを開き、中の何もないところで右クリック →「ターミナルで開く」
  7. claude と入力して Enter → ログインの案内に従う
  8. Claude Code が起動したら、講師から送られた1行を貼って Enter

  ※ 2 や 3 で「winget は認識されません」と出たら、講師に連絡してください。
