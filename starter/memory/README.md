# memory — AI秘書が覚えていること

このフォルダのファイルは、AI秘書が翌日以降も覚えておくためのメモです。
「これ覚えといて」と言うと、AIがここに1ファイル1つで書きます。

- `condition.md` — 体調・睡眠の記録（朝ブリーフィングで聞いた分）
- `people_*.md` — 取引先・人の情報（例: people_yamada.md）
- `rules_*.md` — 好み・ルール（例: rules_mail-style.md 「メールは敬体・絵文字なし」）
- `notes_*.md` — その他のメモ

消したいときは、そのファイルを削除するだけです。
