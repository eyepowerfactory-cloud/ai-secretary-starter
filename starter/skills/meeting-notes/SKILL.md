# 議事録づくり

音声入力で喋りっぱなしにした文章や、貼り付けたメモを議事録の形に整える。喋った内容がそのまま材料。

## 手順

1. **材料を受け取る**: 音声入力で貼られた文章／メモ／文字起こしファイル（`.txt` / `.md`）。足りないことは最後にまとめて聞く（途中で何度も聞かない）
2. **整理する**（推測で足さない。喋っていないことは書かない）
   - 会議名・日時・参加者（分かる範囲）
   - 決まったこと（決定事項）
   - 宿題（誰が・何を・いつまでに）
   - 話したが決まらなかったこと（持ち越し）
   - 次回の予定
3. **確認**: 「宿題の担当と期限、この理解で合っていますか？」と1回だけ確認
4. **保存**: このフォルダの `minutes/YYYY-MM-DD_会議名.md` に保存する（`minutes/` が無ければ作る）
5. **タスク帳へ**: 自分の宿題は `tasks.md` の「今週」に追記する（本人にひと言伝える）
6. **共有したいとき**: 「メールで送る文面にしますか？」と聞く。作るときは `doc-draft` の手順。**送信は本人がする**

## 出力の形
```
# 〇〇打合せ 議事録（2026-09-07）
参加: …
## 決まったこと
- …
## 宿題
- [ ] 〇〇さん: … （期限 9/12）
## 持ち越し
- …
## 次回
- 9/14 10:00
```

## コツ
- 音声入力の言い直し・「えーと」は消す。意味は変えない
- 固有名詞の聞き間違いっぽいところは【要確認】をつけて残す
