Claude Code 「許可を求めない」設定（Windows）

■ これは何
  Claude Code が作業のたびに「許可しますか？」と聞いてくるのを止める設定だけを入れる、
  小さなキットです。Claude Code のインストールや Google 連携は含みません。

■ 使い方（数秒）
  1. zip をデスクトップなどに「すべて展開」する
  2. claude-no-permission-prompt.bat をダブルクリック
     「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
  3. Claude Code（黒い画面 or デスクトップアプリ）を起動し直す

■ 何が変わるか
  対象: %USERPROFILE%\.claude\settings.json
  ・permissions.defaultMode を "bypassPermissions" にする（許可の確認を出さない）
  ・skipDangerousModePermissionPrompt を true にする（起動時の注意画面も出さない）
  ・許可リスト（allow）と禁止リスト（deny）を足す
      禁止例: ファイルの一括削除・ディスク初期化・レジストリ削除・.env や ~/.ssh の読み取り
  ・今ある設定（MCP・フック・モデル指定・既存の許可リスト）はそのまま残す
  ・実行前の settings.json は settings.json.backup に退避する

■ デスクトップアプリで使う人へ
  設定を入れても「Bypass permissions」が選べないときは、
  設定 → Claude Code → 「Allow bypass permissions mode」をオンにしてから
  入力欄のそばのモード選択で「Bypass permissions」を選んでください（Pro/Max はここが必要）。

■ 元に戻す
  同じフォルダの「元に戻す.bat」をダブルクリック（settings.json.backup を戻します）

■ 注意
  ・メール送信や削除など「外に出る・取り消せない」操作まで確認なしで通る設定です。
    仕事のルール（送る前に見せる等）は CLAUDE.md に書いて守らせてください。
  ・うまくいかないときは、同じフォルダにできる setup_log.txt を配布元にお送りください
