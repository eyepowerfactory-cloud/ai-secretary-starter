# スキルカタログ — 次に足せる「秘書の特技」一覧

いま入っているのは4つ（朝ブリーフィング／議事録／文面ドラフト／覚えておいて）。
慣れてきたら、下から選んで伴走レクで追加します。「次はどれ足します？」のメニュー表です。

## すぐ足せる（汎用）
| スキル | 何ができる | 向いている人 |
|---|---|---|
| 企画アイデア出し（noda-ideation） | お題を渡すと、企画案を3つ出す | 新商品・サービスを考える人 |
| Webリサーチ（research-free） | 「〇〇について調べて」で出典付きにまとめる | 誰でも |
| ページ要約（url-summary） | URLを渡すと内容を要約 | 誰でも |
| 請求書・見積書PDF（invoice-create） | 会話で請求書・見積書を作る（自社情報は設定ファイルで差し替え） | 事業者 |
| 提案書PDF（proposal-pdf） | 提案書をA4のPDFに | 事業者・営業 |
| 会議報告書デッキ（report-deck-pdf） | 会議資料をA4横スライドPDFに | 士業・管理会社 |

## 業務が見えてから
| スキル | 何ができる | 向いている人 |
|---|---|---|
| 業務ミニアプリ作り（miniapp） | 在庫・予約・日報などの小さなアプリを5ステップで一緒に作る | 「自分でも作れた」を体験したい人 |
| 要件ヒアリング（requirements-interview） | 「こういうの欲しい」を質問で整理して仕様書に | miniappの前段 |
| スプシ×LINE通知（gas-line-notifier） | スプレッドシートの内容を決まった時間にLINEへ | 予約・空き枠・リマインド |
| 誰でも開けるミニアプリ（gas-json-api-scaffold） | URLを開くだけで使えるアプリの型 | miniappの公開先 |
| キーワード抽出（keyword-free） | 発信ネタのキーワードを洗い出す | ブログ・SNS発信者 |
| YouTubeチャンネル分析（youtube-channel-summary） | チャンネルの傾向をまとめる | 発信者・競合分析 |
| 本格タスク管理（daily-tasks） | tasks.md の上位版。優先順位づけ・進捗追跡 | タスクが増えてきた人 |

## LINE公式アカウントを使っている人向け
| スキル | 何ができる | 注意 |
|---|---|---|
| トーク履歴の丸ごと保存（autoscroll-capture） | LINE公式のトークを自動で遡ってスクロール撮影→1枚の長い画像に | 初回にブラウザ部品の取得あり |
| トーク一括分析（line-chat-analyzer） | 保存した画像から「未回答の人」「未受領の人」を洗い出す | 上とセット |
| LINEを読んで返信案（Chrome連携） | 画面のLINEを読んで返信案を出す。送信ボタンは本人が押す | 読むと既読がつく。大量送信はしない |
