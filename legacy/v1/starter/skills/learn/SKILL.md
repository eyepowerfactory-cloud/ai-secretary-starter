# 覚えておく（memory への記録）

「これ覚えといて」と言われたら、その内容を `memory/` に残す。使うほど自分専用の秘書になる仕組み。

## 手順

1. **何を覚えるか1行で言い直す**: 「『山田さんへのメールは必ずCCに佐藤さんを入れる』ということですね？」
2. **種類を決める**（ファイル名の頭につける）
   - 人・取引先 → `people_〇〇.md`
   - 好み・ルール・言い回し → `rules_〇〇.md`
   - その他のメモ → `notes_〇〇.md`
   - 体調 → `condition.md`（朝ブリーフィングが書く。ここには書かない）
3. **書く**: 既に同じ人・同じテーマのファイルがあれば**そこに追記**（新しいファイルを増やさない）。無ければ新規作成
4. **報告**: 「memory/rules_mail.md に書きました。次から使います」

## ファイルの形
```markdown
# 山田さん（〇〇商事）
- 2026-09-07: メールは必ず佐藤さんをCCに入れる
- 2026-09-07: 呼び方は「山田部長」
```

## ルール
- 本人が言ったことだけを書く。推測で足さない
- パスワード・カード番号・マイナンバーは「覚えられません」と断って書かない
- 「忘れて」と言われたら、該当行を消して「消しました」と伝える
- セッション開始時は `memory/` の全ファイルを読んでから会話を始める（CLAUDE.md にも書いてある）
